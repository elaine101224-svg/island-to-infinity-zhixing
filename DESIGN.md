# Island to Infinity design constraints

Preserve the established interface. The owner rejected the broad visual redesign: no replacement hero, giant infinity motif, new navigation treatment, or global typography/spacing overhaul.

Use the original warm cream, sand, terracotta, sage and amber palette and existing logo. New Term 1 functionality belongs in the existing protected admin shell, using its established controls and panels. Improve functionality and accessibility without changing the public site's visual identity.
