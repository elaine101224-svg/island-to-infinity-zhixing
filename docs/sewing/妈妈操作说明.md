# 凯妈妈的订单管理

商家入口：https://islandtoinfinity.online/sewing/manage
客户入口：https://islandtoinfinity.online/sewing/request

1. 登录后先看“待办”。新需求会显示客户姓名、产品；列表每30秒刷新，回到窗口也会刷新。断网会提示，可点右上角刷新。
2. 点新需求，核对姓名、微信、House、心理预算、尺码面料偏好、设计说明、附件和后补说明。点“转为订单草稿”，编号不变；不要另建一单。
3. 在“产品要求”填每款数量、尺码、布料、颜色、图案等；可以根据预算推荐。保存关键变更会留新版本，旧确认失效。
4. “报价与确认”先记录免费打样，目标一周内完成，日期按实际沟通填写。记录样衣完成及送校日期、上传样衣照片，生成“样衣／沿用标准”确认链接发给客户。
5. 客户明确确认样衣后再填最终报价和协商交期，通常尽量符合预算；再发“报价与交期”确认链接。打开链接不算确认，客户必须点击提交回复。
6. 两项确认都有了才能在“生产安排”开始大货。缝纫队安排制作，印花选择真实合作方，记录实际进度及完成日期。
7. 付款按单选定金加尾款或一次结清；“钱款”只记真实到账、退款和实际日期，不把口头承诺当到账。交付后欠款仍留在待办。已归档欠款也会提醒。
8. 制作错误或客户修改，可在“问题与修改”登记免费补做、数量、原因、负责人、进度和照片；补做不会自动加应收。改变正式规格须重新发确认。

“客户补充资料链接”可让客户继续补图和说明，不改变正式规格或金额。客户保留首次提交得到的私密链接即可；链接丢失可生成新链接，旧链接失效；也可撤销。私密链接不要放群聊或公开发布。

四个House旧单：点“新增订单”，展开“补录已经在制作的历史订单”，填真实客户、产品、数量、实际阶段和资料来源；未知日期留空。历史单先不进正式金额统计，不需要重做过去工序。后续根据真实凭证补录线下确认及收付款，核实后再纳入统计。不要猜填金额、交期、付款或确认。

附件／保存失败时先重试或刷新。系统沿用需求编号和附件编号。若提示资料已更新，刷新核对后再保存；不要为重试另建订单。
