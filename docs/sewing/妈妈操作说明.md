# 妈妈使用说明

当前商家页只保留需求查看与接单决定；面料、样衣、最终价格、生产、付款和交付细节在微信群沟通。

1. 打开 `/sewing/manage`，使用已开通的业务账号登录。首次登录按提示修改密码。
2. 新需求排在前面，状态为“待决定”。直接查看客户 Teams 姓名、微信、产品、数量、每件预算、面料选择、设计要求、日期和其他说明。
3. 图片可点开原图；PDF、尺码表等文件可下载。客户通过私密链接补图或补充说明后，点“刷新需求”即可看到。
4. 选择“接单”或“不接单”，再点确认。不接单必须填写原因。决定沿用原需求编号保存，不重复建单；已处理需求不可再次作出相反决定。
5. 客户自己的私密链接会显示“等待决定／已接单／不接单”。内部原因和财务资料不会公开。

预算是每件心理预算，不是已确认售价。结合客户要求和市场价尽量达到预算；最终价格需在样衣确认后沟通确定。

流程：需求与预算 → 免费打样 → 样衣送校确认 → 最终报价 → 客户确认报价 → 生产及印花 → 付款 → 交付与尾款。免费打样目标约一周，不自动承诺交期；尺码表由后续整理提供。面料可由客户填写或请 Kaiyan 妈妈决定。

没有真实凭证时，不补造历史确认、日期或金额。既有业务记录、确认版本和收付款记录保留；本次简化不改动这些数据。测试数据与正式统计继续隔离。
