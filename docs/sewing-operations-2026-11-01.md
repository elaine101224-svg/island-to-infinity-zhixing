# 缝纫订单管理第一版

入口：https://islandtoinfinity.online/sewing/manage 。客户确认入口为每次生成的独立私密链接，不需要账号。沿用既有 Supabase 与 Vercel 项目，未改变全站注册或访问范围。

## 妈妈使用
1. 使用业务账号登录；首次使用必须更换初始密码。正常使用续期30天，最长90天重新登录。
2. 点击新增订单，录入客户、产品、数量、客户期望日期。已有询价在订单列表转为草稿，保留原编号。
3. 补充产品要求和尺码数量，保存报价，生成报价确认链接发给客户。
4. 上传样衣或原标准记录，发送样衣／沿用标准确认。客户确认当前规格后才能开始大货。
5. 生产安排中更新负责人、预计和实际日期及异常；印花工序可上移或下移。
6. 钱款中记录实际收款、退款、成本和供应商付款；客户承诺日期不算到账。凭证上传时选择财务可见范围。
7. 待办自动汇总临期、问题、待确认和待收款。已交付但未结清继续显示。

账号：网站管理员登录原后台后打开订单管理的设置，可开通业务负责人、重置密码；业务负责人可开通协助账号并逐单授权。财务权限独立设置。重置、停用会撤销已有会话，不删除历史。初始密码不在本文件或Git中保存；本地 private-media 中的受限凭据文件须仅交给业务负责人本人。

## 数据与部署
权威记录仍是 sewing_orders，新增 work 字段，不复制订单。原询价保留。迁移：20261101085614_sewing_operations.sql 与 20261101090012_sewing_financial_attachments.sql，已应用。scripts/sewing-operations-schema.sql 是隔离测试的新建完整结构，不应在已迁移正式库重复执行。
新表启用RLS，anon/authenticated无直接权限，业务RPC仅service_role可执行。服务器逐次校验业务会话、订单授权、财务权限；数据库重复校验权限、版本、确认状态。令牌仅存SHA256摘要；密码用随机盐scrypt。客户访问令牌在链接片段中，API通过授权头提交，不放查询字符串。确认快照不可变，回复显式提交，重复提交不产生冲突记录。财务附件不能发送到客户规格确认网页。
金额整数分存储；历史实际收付款和报价不可覆盖。新报价未确认期间保留旧版已确认应收，草稿金额单列。成本与供应商付款分开，避免重复计算。
Vercel沿用项目 prj_Tx0TmMQMeWcJBws2feq76BfXAgcm，先 --prod --skip-domain 构建检查，再 promote。上一生产回退目标 dpl_84nUa5nhDBZJi8TL8t3DKo9Ejf2p。应用回退不要删除新增表或恢复旧订单快照覆盖新业务资料。

## 导出和附件备份
设置中提供订单CSV、财务明细CSV、完整JSON。JSON包含当前授权订单、财务明细、固定确认快照及附件编号。附件继续存储于既有私密 sewing-private 桶；按JSON清单使用已授权会话访问 /api/sewing-ops/orders/订单ID/files/附件ID 下载原图。财务附件需财务权限。不要将桶公开或将客户链接当备份权限；完整灾备还应由管理员备份数据库表、审计表和该私密桶对象。客户链接原始令牌只生成时显示，不可从数据库恢复；遗失应撤销并重发。
