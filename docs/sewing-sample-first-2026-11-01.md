# 免费打样及客户补充资料升级

## 入口与业务
客户端：https://islandtoinfinity.online/sewing/request
商家端：https://islandtoinfinity.online/sewing/manage
保留既有业务账号，无公开后台注册。客户首次提交无需登录。

客户端新增整单心理预算、尺码和面料指定／推荐选择、颜色及要求、图片／PDF／CSV／XLSX文件。首次仅产品、数量、姓名及联系方式必填。生成需求编号和90天私密补充链接，提交重试沿用编号；补充说明与文件关联原订单。商家可生成新链接使旧链接失效，或撤销；凭证只存令牌摘要。

新单流程：需求与预算 → 免费样衣 → 样衣确认 → 最终报价 → 最终报价确认 → 大货。所有打样费固定0元；开始、预计完成、实际完成及送校日期分别记录，预计日期由业务人员填写，不自动承诺一周交付。样衣可不含报价单独确认；填写最终报价需要样衣完成及当前规格样衣确认。样衣确认不因随后新增报价失效。大货同时要求当前规格样衣确认和最终报价确认。

付款按单选择定金尾款或单次结清，不默认比例；付款日期和定金金额由业务负责人填写。实际收款与退款用整数分存储，显示“已收金额”；已收金额是实际收款扣除实际退款，退款另列。承诺付款不算到账，草稿报价不计应收。实际成本、供应商付款分开；成本未完整不显示最终利润。

免费补做记录产品、数量、原因、处理方案、负责人、进度、照片和前后规格；不自动加客户应付金额。关键修改生成规格新版本并保留specHistory，旧确认不能覆盖新规格。

新增订单表单中展开“补录已经在制作的历史订单”，填写真实客户／House、产品数量、期望日期、当前阶段及资料来源。历史记录默认未核实，不计正式金额汇总。可逐步补规格、真实样衣及最终报价的线下确认凭证、实际收付款；资料核实后由财务授权人员确认纳入统计，不自动补造任何确认。当前阶段保存在历史记录中，不要求把旧工序逐个重新完成。未知历史日期不应猜填。
